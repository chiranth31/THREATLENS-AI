# THREATLENS AI

**See the Threat. Stop the Click.**

AI-Powered Phishing URL Detection & Threat Analysis Platform using Machine Learning.

## 🚀 Live Demo

🔗 **[Open THREATLENS AI – Live Web Application](https://threatlens-ai-security.vercel.app/)**

Scan a URL and receive an AI-powered **SAFE** or **PHISHING** verdict with risk score, model confidence, URL features, security analytics, and incident monitoring.

## 👥 User Roles & Access Control

ThreatLens uses administrator-controlled user provisioning rather than open registration. This prevents unauthorized users from creating accounts and provides role-based access for administrators and security analysts.

**Analyst** — An authorized security user who uses ThreatLens AI to scan URLs, investigate phishing detections, review incidents, and analyze security data, while the **Administrator** controls users and system access.

Only an authorized administrator can create accounts and decide who is allowed to access the ThreatLens security workspace.

## 🛡️ Key Features

- AI-powered phishing URL detection
- SAFE / PHISHING classification
- Risk and confidence scoring
- Random Forest, Decision Tree, and Logistic Regression models
- URL feature analysis
- Incidents & Alerts
- Scan History
- Threat Intelligence
- ML Analytics
- Administrator-controlled user management
- Role-based access control
- Security and audit monitoring

## 🧠 Machine Learning

ThreatLens AI uses URL-based feature engineering and machine learning models to classify URLs as legitimate or phishing.

The system compares multiple models and uses the best-performing model for live prediction.
